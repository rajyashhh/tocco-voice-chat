# Tocco Voice Live — Brand Assets

Place official brand assets here:

## Required Files

| File | Purpose | Size |
|------|---------|------|
| `logo.png` | App logo (used in navbar, fallback) | 256×256 or higher |
| `favicon.ico` | Browser favicon | 32×32 or 48×48 |
| `og-image.png` | Social media preview image | 1200×630 |

## Guidelines

- Use the official Tocco Voice Live logo from the mobile application
- PNG with transparent background preferred for `logo.png`
- `og-image.png` should include the logo and "Tocco Voice Live" text
- Do NOT use placeholder or generic logos
- Keep files optimized for web (under 200KB for logos, under 500KB for OG image)

## Current Source

The logo is currently managed through the Laravel admin panel (Brand Settings).
To export it for the website:
1. Download from the admin panel
2. Place here as `logo.png`
3. The website will use this static file instead of fetching from the backend
